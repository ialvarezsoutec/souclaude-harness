Casuística 4 · Adopción de la metodología

Máquina nueva

Integrante nuevo o existente: todo lo de esta lista es por máquina, no por proyecto — nada se hereda solo de tu otra computadora

La premisa

El harness distribuye archivos dentro del repo, pero no puede instalar software en tu equipo ni hacer logins por ti. Estos pasos son tuyos, una sola vez por máquina; después el token de gh, la conexión del Vault y el OAuth de Jira quedan guardados.

Los seis pasos, en orden

Requisitos: Node ≥ 22.4, git, y GitHub CLI autenticado. Sin gh el agente pushea la rama pero el PR queda para abrir a mano. winget install GitHub.cli gh auth login # GitHub.com · HTTPS · browser gh auth status # ✓ Logged in
Clona el repo del proyecto en una ruta fuera de OneDrive — las carpetas sincronizadas corrompen .git/ y generan copias en conflicto.
Clona el Vault y conéctalo, también fuera de OneDrive: git clone <VAULT_REPO> <RUTA_VAULT> npx souclaude upgrade --vault-path <RUTA_VAULT>
Añade a mano "project" a .claude/vault.local.json (el CLI aún no lo escribe; sin él, el hook queda ciego en silencio si el Vault tiene más de un proyecto): { "path": "...", "repo": "...", "project": "Project-<PREFIJO>" }
Autoriza el conector Jira: en una sesión interactiva de Claude Code escribe /mcp y autentica Atlassian (OAuth en el navegador, una vez por máquina — solo la persona puede).
Verifica: abre una sesión nueva — el hook de SessionStart debe imprimir el tablero de Project-<PREFIJO>. Si no aparece, el paso 3 o el 4 quedaron mal.
Recuerda: este archivo (vault.local.json) está gitignorado a propósito — la ruta es de cada máquina. Cada integrante repite estos pasos en la suya; no se copia de otra computadora.

Cierre: la verificación asistida

Prompt de verificación para pegarle al agente
Antes de dar la máquina por lista, pídele al agente el diagnóstico completo — que reporte, sin arreglar nada todavía: 
Verifica que esta máquina quedó bien conectada a la metodología: gh autenticado,
Vault clonado y conectado con el campo project en vault.local.json, conector de
Atlassian respondiendo y hook de sesión leyendo el tablero. Repórtame qué está
bien y qué falta, sin arreglar nada todavía.
